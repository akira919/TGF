到了小李醒來的時候他又想摸小如,小如打了他一巴掌,真是笑死我了.後來到了墾丁以後 我們到處去逛 蠻好玩的 到了晚上 我們一群男生跟班上一群女生一起在一間房間打牌 後來我提議玩國王遊戲 但是大家說懲罰不能太過分,當然我有我的辦法,我對著小慧按著B鈕,小慧是班上的班花之一,讓他寫下了一些令人噴血的懲罰,然後一直到有人抽到脫衣服的懲罰,大家就想知道是誰寫的,我再度按下B鈕,控制小慧說,我寫的要玩就玩刺激一點,其他男生當然頻頻說好,其他女生則是有點害羞,但是畢竟小慧是班花,說的話蠻有影響力的,於是我們重寫規則,男生們都寫的誇張,接吻,種草莓,脫衣服,自慰都有,後來玩的時候小婷抽到了脫衣服,為了帶動氣氛 我又控制小婷,讓他脫光上衣,露出了內衣,他的胸部很大,我還控制他說一些下流的話,像是想看我自慰就來阿\~看你們有本事嗎\~這樣的情況下氣氛更熱烈了 男生當然不怕脫 抽到就脫了後來小佩抽到了幫男生打手槍 在大家的氣氛之下 小佩選擇了幫我 他的技巧不是很好,不是很舒服 但是也還不錯 平常天天看的到的同學 今天居然用手在幫我的小弟服務,後來大家越寫越火熱,小婷得幫小李口交等等,幾乎男女生都脫光了,大家也都激情如火 我把控制取消以後 小慧居然還是一樣淫蕩 看來他原本就是這樣了,之後看看時間差不多有人要檢查了 我們就穿上衣服各自回房間.
